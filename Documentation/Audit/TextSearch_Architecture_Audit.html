Сохранено

  • Public/protected API, defaults и visibility.
  • Nested-key schema, WABI framing, AES-CTR output и queue payload.
  • Flush при Count > 100000, то есть на 100 001-й ссылке.
  • Двустороннее чтение, update и reopen plain/encrypted индексов.

Изменено намеренно

  • Bulk WABI mutation, trailing-zero trimming и удаление пустых entries.
  • Устойчивый deferred worker с coalescing, parking и reopen.
  • One-sided ranges, single-pass query inputs, непортящийся cache.
  • Fail-fast invalid configuration и строгая migration.

Открытые действия

  • P0: нет; MergeOr2 закрыт после корректного MediumRun.
  • P1: подтвердить, что tightening invalid-input/migration — утверждённый контракт.
  • P2: измерить retained heap / peak working set / deferred high-water.
  • P2: реальный legacy queue row → current worker остаётся не доказан end-to-end.

4. Архитектурный поток и границы состояния

Transaction APIInsert / append / remove / search; public signatures unchanged.
ParserLowercase, chunk, suffix, exact; now deterministic dedup and fail-fast.
Pending rows5-byte searchable key: uint document id + marker.
Word changesSorted application; new refs flush at 100 001.
WABIBulk bitmap mutation, trim, SIMD on net8.
Blocks4-byte payload length + GZip/Biser + reserve padding.
QueryPrefix/exact composition, cache, external ID bounds.

Синхронный путь

Commit вызывает indexing немедленно; logical result видим вместе с commit. Новая реализация группирует изменения слова и выполняет один bulk WABI mutation.

Deferred путь

Commit сохраняет durable task в _DBreezeTextIndexer; один worker объединяет wake-ups, обрабатывает batch и удаляет task только после успешной транзакции.

Дисковая граница

Схема nested tables и payload framing сохранена. Trimming/padding/page placement могут менять физические bytes без потери cross-readability.

7. Parser, batching и block policy

Parser/tokenization

Reference строил SortedDictionary<string,WordDefinition>, промежуточные StringBuilder/List и проглатывал исключения. Current deduplicate-ит напрямую (SortedDictionary<string,byte>; net8 — spans/SortedSet), сохраняет lowercase/chunk/suffix/exact semantics и минимальную searchable длину 3. MaximalWordSize < 1 теперь бросает исключение.

Word changes

Reference накапливал document sets и mutировал WABI по одному id. Current хранит WordChange.RemoveFrom/AddTo, сортирует слова ordinal и выполняет bulk mutation. Полный change-set по-прежнему ограничен размером транзакции; новый refs buffer ограничен flush.

Flush invariant

NewWordReferenceFlushThreshold = 100000 и условие строго Count > threshold. Следовательно, flush происходит при добавлении 100 001-й записи — как в reference tmpWrds.Count > 100000. Финальный flush сохранён.

8. WABI, composition и query cache

Bitmap mutation

Добавлены bulk Add(IEnumerable<int>, bool) и IsEmpty. Clearing отсутствующего high id — no-op; trailing zero bytes обрезаются. Формат не меняется: старый reader принимает короткий bitmap.

Merge

AND/OR/XOR/EXCLUDE обрабатывают null/empty безопасно и возвращают trimmed result. Net8 использует Vector<byte>/Span для hot loops. Логика проверена randomized set-model test.

Composition/cache

Cache публикуется только после успешного полного вычисления; reference мог пометить блок computed до exception. Повторное использование child block больше не мутирует его cached result. Missing terms и OR/XOR/Exclude согласованы.

P0 закрыт — прежний FAIL был недостоверен: при out-of-process запуске BenchmarkDotNet сгенерированный child project восстановил ProjectReference на текущий checkout, поэтому опубликованные как reference числа 18,90/19,82 μs не измеряли baseline a834 и отброшены. Исправленный одинаково фильтрованный MediumRun использовал один source (SHA-256 08F78EB3…07A), две фиксированные DLL и InProcessEmitToolchain: baseline 546,715 μs, current 19,150 μs, delta −96,497%. Allocations: 128,08 → 128,04 KB/op (−0,031%). Logical/randomized WABI и composition tests — PASS.

Статическое отличие hot path: reference WABI.cs:230-254 после поиска max длины выполняет один nested scalar loop; current net8 WABI.cs:333-373, 500-541 сначала сканирует non-empty operands/indices, затем вызывает Span/Vector<byte> OrInto и в конце TrimResult. Исправленное измерение согласуется с ускорением этого hot path; production fix не требуется.

Остальные WABI gates: Medium MergeAnd2 current 20,66 μs vs reference 21,70 μs (−4,79%, PASS). Short median-of-medians: sparse enumeration +0,26%; dense −0,01%; MergeAnd16 −1,21%; MergeOr16 +1,21%.

Ranges и reusable blocks

Reference применял external bounds только если заданы обе границы и мог вернуть неверный full set при non-overlap. Current конвертирует каждую заданную границу к ближайшему существующему external id, поддерживает one-sided bounds, обнуляет converted bounds между enumerations и возвращает empty для inverted/non-intersecting ranges. Это полезная correction, но observable semantic change валидного вызова с одной границей, поэтому классифицировано как contract drift + intentional correction, а не как «эквивалентность».

9. AES-CTR и migration

AES-CTR

  • Key sizes 16/24/32 и IV 16 теперь валидируются в constructor; caller arrays клонируются.
  • Counter construction, fixed IV и ciphertext vectors сохранены; net8 выполняет in-place XOR и EncryptEcb со stack buffers.
  • Prefix invariant подтверждён ASCII, block boundary и Unicode vectors.
  • Security characteristic не изменён: deterministic fixed-IV CTR раскрывает равенство prefix и не аутентифицирует ciphertext.

Migration plain → encrypted

  • Public method прежний.
  • Current отклоняет уже encrypted source и non-empty destination.
  • Проверяет searchable keys и 8-byte word refs.
  • Копирует metadata/blocks/words, re-encrypts text/word keys и сразу индексирует pending marker=1 rows в target.
  • Reference мог смешать destination или повторно encrypt source; tightening observable для ранее допускавшегося, но документированно нецелевого вызова.
Клонирование key/IV меняет один edge-contract: мутация caller arrays после constructor больше не меняет будущий ciphertext. Это безопасное исправление, но вызывающий код, намеренно полагавшийся на mutability, увидит отличие.

Полный net8 regression harness — NOT PROVEN как единый run

Memory retention — NOT PROVEN

BDN allocations измерены. Forced-GC heap, peak/retained working set и deferred high-water — нет. Статический риск batch reuse указан, но численного verdict нет.

Reference build matrix — частично runtime

Reference net8 и net472 собраны и использованы для API/runtime evidence. Binding map других targets проверен по source; current Release matrix собрана полностью. Нельзя утверждать новый runtime PASS reference net6/netstandard/netcoreapp/Portable на основании current build.

Физическая byte identity

Plain steady read-only полностью byte-stable. Encrypted post-update первый reopen применил recovery cleanup к .rol, data-файл не изменился; второй read-only reopen byte-stable. Это честно не маркируется как «все файлы всегда неизменны».
